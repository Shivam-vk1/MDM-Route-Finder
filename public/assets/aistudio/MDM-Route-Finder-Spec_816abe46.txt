MDM ROUTE FINDER - COMPLETE APP SPEC
=====================================

Ye poora app ka spec hai, ek jagah. Isko seedha dusre app/AI tool me paste kar sakte ho. Neeche ek ready-to-paste prompt hai, uske baad woh gotchas jo humne is build me jhele, taaki naye app me dobara na aaye.


SHORT ME APP KYA HAI
--------------------
MDM Route Finder ek static web app hai (koi backend/database nahi). Kanpur Kitchen (TAPF) ki 129 schools ki list, 6 routes me. Kisi bhi school ko search karke ek tap me uski location, route, driver, route executive aur school contact mil jaata hai, saath me map aur Google Maps directions. Data Excel sheet (OS1_detail.xlsx) se nikala gaya.


KAISE BANAYA (BUILD PROCESS)
----------------------------
1. Excel se Python (openpyxl) me 18 columns padhe, text clean kiya (strip), phone numbers string me convert kiye, aur 129 records ka JSON banaya.
2. JSON ko data.js me "const SCHOOLS = [...]" ki tarah embed kiya, taaki server/fetch ki zaroorat na pade.
3. 3 files banayi: index.html (layout + CSS), app.js (logic), data.js (data).
4. Map ke liye Leaflet.js (CDN se) use kiya.
5. GitHub repo (public) me upload karke GitHub Pages se host kiya.

Tech stack: Plain HTML + CSS + vanilla JavaScript, Leaflet 1.9.4, Google Fonts (Fraunces, Inter, IBM Plex Mono), OpenStreetMap tiles. Koi framework ya build step nahi.


DATA STRUCTURE (EXCEL COLUMNS -> JSON FIELDS)
---------------------------------------------
NODE_GROUP                       -> nodeGroup
NODE GROUP NAME                  -> nodeGroupName
SCHOOL_NAME                      -> schoolName
UDISE-CODE                       -> udise
ROUTE CODE                       -> routeCode
NODE CODE                        -> nodeCode
ROUTE NAME                       -> routeName
latitude / longitude             -> lat / lon (numbers)
Driver Name / Contact            -> driverName / driverContact
Route Executive Name / Contact   -> routeExecutive / routeExecutiveContact
Address / Pincode                -> address / pincode
School SPOC name / number        -> spocName / spocContact (ye school ka contact number hai)
School Category                  -> category

Har record me ek id (1 se 129) bhi hai.
6 routes: BAIRI, Barra, GOVIND NAGAR, KIDWAI NAGAR, Shastri Nagar, VIJAY NAGAR.


FEATURES (JO ABHI FINAL APP ME HAIN)
------------------------------------
- Search box: school name, node group name, UDISE, node code, route code, route name, address, SPOC name, pincode me live match (case-insensitive), clear (x) button ke saath.
- Route chips: "All routes" + 6 route chips, har route ka apna color dot. Route select karne par list/map filter hota hai aur map us route ke schools par fit ho jaata hai, schools ke beech dotted polyline.
- Result counter: "X of 129 schools - route: ..."
- List view: card me school name (tappable), route tag (colored), node code, UDISE, category, address, aur ek chhota pin-icon button jo seedha Google Maps directions kholta hai.
- Map view: dark-style map, har school ka colored dot marker (route ke color me). Marker tap par popup (name, route, address, "Open in Google Maps"), aur selected marker bada ho jaata hai.
- Detail drawer (kisi bhi school ya marker tap par): mobile par bottom sheet (85dvh), desktop par right side panel. Isme:
    * Action buttons: Directions, Call School (SPOC number), Driver (call)
    * School section: node group, UDISE, category, pincode
    * Route section: route name, route code, node code
    * Address
    * Contacts: driver, route executive, school SPOC, sab numbers tel: links
- Layout: desktop par list (380px) + map side by side; mobile par List/Map toggle.
- First-load beta notice (English): beta disclaimer + 2 usage tips + "Got it" button. Dismiss karne par localStorage me save hota hai, us device par dobara nahi dikhta.


DESIGN
------
- Dark green theme: bg #12211a, raised #1a2e24 / #21382b, line #2c4436, text #f2ede0, accent amber #e8a33d, sage #7fb298.
- Route colors: BAIRI #e8a33d, Barra #7fb298, GOVIND NAGAR #7c9ee0, KIDWAI NAGAR #d16257, Shastri Nagar #c99be0, VIJAY NAGAR #e0c25c.
- Fonts: Fraunces (headings), Inter (UI), IBM Plex Mono (codes/numbers).

READY-TO-PASTE PROMPT (DUSRE APP KE LIYE)
-----------------------------------------
Build a single-page, mobile-first static web app (HTML + CSS + vanilla JS, Leaflet for maps, no backend, no build step, deployable on GitHub Pages) called "MDM Route Finder" for a school meal-delivery kitchen.

DATA: 129 schools in 6 routes, loaded from a data.js file: const SCHOOLS = [{id, nodeGroup, nodeGroupName, schoolName, udise, routeCode, nodeCode, routeName, lat, lon, driverName, driverContact, routeExecutive, routeExecutiveContact, address, pincode, spocName, spocContact, category}]. spocContact is the school's contact number.

FEATURES:
1. Sticky header with title, live search box (matches school name, node group, UDISE, node code, route code/name, address, SPOC name, pincode; clear button), List/Map toggle, horizontally scrollable route filter chips (All + one per route, each with its own color dot), and a result counter.
2. List view: cards with tappable school name, colored route tag, node code, UDISE, category, address, and a small pin button that opens Google Maps directions (https://www.google.com/maps/dir/?api=1&destination=LAT,LON) in a new tab.
3. Map view (Leaflet + OpenStreetMap tiles, dark look via CSS filter on tile pane only): colored circle markers per route; popup with name, route, address, "Open in Google Maps"; selecting a school enlarges its marker; selecting a route draws a dotted polyline between its schools in row order and fits bounds.
4. Tapping any school (card or marker) opens a detail drawer: bottom sheet on mobile, right panel on desktop. Contains action buttons (Directions, Call School via spocContact, Call Driver), School, Route, Address and Contacts sections; all phone numbers are tel: links.
5. Desktop: list + map side by side. Mobile: List/Map toggle; opening the drawer must NOT switch views.
6. First-load dismissible notice modal in English: beta disclaimer (minor bugs may appear, fixed in upcoming updates) + 2 usage tips (how to search/filter, how to open a school profile). "Got it" saves to localStorage so it never shows again on that device.
7. Empty state: "No schools found".

DESIGN: dark green theme (#12211a bg, #1a2e24 cards, #e8a33d amber accent, #f2ede0 text), Fraunces headings, Inter body, IBM Plex Mono for codes. Route colors: BAIRI #e8a33d, Barra #7fb298, GOVIND NAGAR #7c9ee0, KIDWAI NAGAR #d16257, Shastri Nagar #c99be0, VIJAY NAGAR #e0c25c.

TECH RULES: drawer/overlay z-index must exceed Leaflet's (use 5000+; notice modal 6000+). Use 100dvh for mobile heights. Use OpenStreetMap tiles (no API key). Escape all data before inserting into HTML. Wrap localStorage in try/catch.


GOTCHAS (JO HUMNE SEEKHA, NAYE APP ME YAAD RAKHNA)
--------------------------------------------------
1. Z-index bug: Leaflet ka z-index 1000 tak jaata hai. Drawer ka z-index 90 tha to drawer map ke peeche dab gaya. Fix: 5000+.
2. Mobile par drawer khulne par auto Map-switch confusion create karta tha. Hata diya.
3. CARTO dark tiles ne API key mandatory kar di, map blank ho gaya. OSM tiles + CSS filter use karo.
4. GitHub Pages free me sirf public repo par chalta hai. Matlab data.js (driver/SPOC numbers) public URL par hai. Real privacy ke liye login-gated hosting chahiye (Cloudflare Pages + Access free tier me ho sakta hai). App ke andar password lagana real security nahi hai, kyunki data file direct fetch ho sakti hai.
5. Route line road-route nahi hai. Wo sirf Excel ke row order me schools ko straight-line se jodti hai. Agar actual dispatch order chahiye to Excel me schools usi order me rakho, ya naye app me proper routing API (OSRM/Google Directions) add karo.
6. Data update manual hai: data.js edit karke reupload karna padta hai. Agar baar-baar update hota hai to naye app me Excel upload/parse feature ya Google Sheet se data lena better rahega.
7. Phone numbers string me store karo, number me nahi, warna leading zeros ya formatting bigad sakti hai.
